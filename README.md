# 🌦️ Weather Website

A simple and responsive weather application built using **HTML, CSS, and JavaScript**. The application allows users to search for any city and view real-time weather information using the **WeatherAPI**.

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature (°C)
- ☁️ Show weather condition
- 🖼️ Display weather icon
- 📱 Responsive user interface
- ⚡ Fast API-based weather updates
- ❌ Error handling for invalid city names

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- WeatherAPI

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/sagarjakanur/weather-website.git
```

### Navigate to the project folder

```bash
cd weather-website
```

### Open the project

Open `index.html` in your browser.

---

## 🔑 API Used

This project uses **WeatherAPI** to fetch live weather information.

Website:
https://www.weatherapi.com/

Replace your API key inside `script.js`:

```javascript
const apiKey = "YOUR_API_KEY";
```

## 📖 How to Use
